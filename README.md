# Mrl Store Gold - Catálogo Exclusivo

Catálogo online interativo desenvolvido para a **Mrl Store Gold**, facilitando a escolha de produtos e o envio direto de pedidos via WhatsApp de forma rápida e automatizada.

## 🚀 Acesse o Site
Você pode acessar o catálogo em funcionamento através do link:
👉 [https://mrlmarques.github.io/catalogo-vendas/](https://mrlmarques.github.io/catalogo-vendas/)

## ✨ Funcionalidades
- **Navegação por Categorias:** Filtre facilmente entre Smartwatches, Fones de Ouvido e Computadores.
- **Carrinho Dinâmico:** Adicione e remova itens calculando o valor total em tempo real.
- **Tema Exclusivo:** Design moderno em preto e dourado voltado para o comércio de eletrônicos.
- **Fechamento via WhatsApp:** O pedido é formatado de forma limpa e enviado diretamente para o atendimento da loja.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estrutura da página)
- **Tailwind CSS** (Estilização responsiva e moderna via CDN)
- **JavaScript** (Lógica do catálogo, carrinho e integração com WhatsApp)
- **GitHub Pages** (Hospedagem gratuita do site)
